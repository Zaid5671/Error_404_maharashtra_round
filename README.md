# Black Box: A Flight Recorder for AI Agents

Team **Error 404**, Maharashtra Round.

Black Box is an AI-powered debugger for AI agents. It records agent execution traces and learns from successful and failed runs to pinpoint the step that caused a failure. It explains why that step was flagged, and lets you replay the run from a checkpoint with a fix to see whether the outcome changes.

🚧 Work in progress (24-hour hackathon build).
